# Lorax AI Voice Studio — RVC + RMVPE

Приложение преобразует **саму запись голоса** через официальный RVC. RMVPE извлекает высоту тона, а модель персонажа меняет тембр. Исходная запись задаёт слова, ритм, паузы и интонационный рисунок. Качество переноса эмоций зависит от записи и обучения модели; точное совпадение не гарантируется.

Здесь нет распознавания и повторной озвучки текста. Перевод и подмена текста исключены из процесса. По умолчанию pitch shift = 0, rms mix = 0 (динамика громкости исходника), protect = 0.33. Ползунок высоты меняет её на постоянное число полутонов, сохраняя контур и темп.

## Установка и запуск на Windows

Используется Python 3.11 и PyTorch 2.5.1. Для запуска нужны Git и доступ в интернет при первой установке.

```powershell
cd Lorax-AI
.\setup_rvc.ps1
.\run.ps1
```

Установщик использует `venv`, устанавливает зависимости, скачивает официальный RVC в `vendor/RVC`, HuBERT, RMVPE и FFmpeg. Базовые модели и зависимости занимают несколько ГБ. На новом окружении с NVIDIA установщик выбирает CUDA 12.1; в существующем сохраняет установленную совместимую пару Torch/Torchaudio. Доступность GPU отображается в приложении. Адрес: http://127.0.0.1:8000. Для последующих запусков достаточно `start.bat` из любой из двух папок.

Закреплённая версия RVC: `81eed5e8f68b6bed1789f682fe78cdd324495afc`. Используется `python -m infer.cli`, без запуска Gradio и без его конфликтующих зависимостей. Каждая конверсия запускается в отдельном процессе; модели загружаются заново и видеопамять освобождается при завершении. Это обработка записей до 30 секунд, а не потоковый микрофонный эффект. Одновременно обрабатывается одна запись.

## Голоса персонажей: нужны обученные модели

Без обученной модели персонажа преобразование недоступно. Базовые HuBERT/RMVPE не содержат голос Лоракса или Пипсквика.

```text
models/
  lorax/
    voice.pth      # inference-модель RVC v1/v2, обученная с F0
    voice.index    # соответствующий added-индекс, если есть
  pipsqueak/
    voice.pth
    voice.index
```

Допускается единственный `.pth` с другим именем. Если их несколько, выбранный нужно назвать `voice.pth`. Индекс должен соответствовать именно этой модели; `trained_*.index` не подходит. Без индекса retrieval автоматически отключается и API возвращает фактический `index_rate: 0`. Без `.pth` API возвращает 503 с пояснением. WAV-запись не заменяет RVC-модель.

## Если готовых моделей нет

Для Лоракса добавлен датасет в `voices Lorax/`: 8 MP3-файлов, из них 7 уникальных. После исключения точной копии длительность составляет **312,84 секунды (5 минут 13 секунд)**. Подготовлено 137 сегментов для первого обучения RVC v2 с F0/RMVPE. Оригиналы сохранены. Подробный список файлов и хешей: `training/lorax/dataset.json`.

### Обучить и подключить Лоракса одной командой

```powershell
venv\Scripts\python.exe -m pip install -r requirements-training.txt
venv\Scripts\python.exe train_lorax.py --epochs 100
```

Скрипт исключает точные дубликаты, декодирует и нарезает речь, извлекает F0 через RMVPE и признаки HuBERT, строит retrieval-индекс и запускает официальный RVC CLI. Настройки: v2, 40k, F0 включён, batch size 1, segment_size 6400, без кэширования датасета в GPU — для RTX 2050 с 4 ГБ. Обёртка `rvc_train_worker.py` загружает данные в одном процессе; для совместимости CUDA на Windows отключён API cuDNN v8 (используется v7). Предобученные G/D и образцы тишины скачиваются из официального хранилища RVC. Используется текущее окружение приложения с дополнительными зависимостями CLI, без Gradio.

После завершения `voice.pth` и `voice.index` автоматически помещаются в `models/lorax/`. Скрипт проверяет настоящее преобразование записи и сохраняет пробный WAV. Состояние и путь к пробной записи находятся в `training/lorax/status.json`; журнал обучения — `vendor/RVC/logs/lorax_v2_40k/train.log`.

Обучение может занять продолжительное время. Промежуточные checkpoint сохраняются каждые 10 эпох; повтор той же команды продолжает эксперимент. Чтобы продолжить до 200 эпох, используйте `--epochs 200`. Если набор исходных записей изменился, задайте новое имя через `--experiment lorax_v2_40k_more`, чтобы сохранить старый эксперимент. Для одной подготовки без обучения: `--prepare-only`.

Качество первой модели нужно оценить на вашей речи. Более длинный и разнообразный чистый датасет может улучшить результат; [авторы RVC рекомендуют не менее 10 минут малошумной речи](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/docs/en/README.en.md#features). Для Пипсквика пока есть только короткие образцы в `reference/pipsqueak/`; отдельная обученная модель ещё нужна.

### Обучение через официальный WebUI

Для обучения через WebUI используйте отдельное окружение: его Gradio требует другие версии FastAPI/Pydantic. Следуйте [официальной установке RVC](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/docs/en/README.en.md#environment-setup), выбрав NVIDIA CUDA 11.8 для RTX 2050. Текущая полная установка upstream рассчитана на Python 3.12. Не устанавливайте её WebUI requirements в `venv` этого приложения.

1. Запустите WebUI командой `python webui.py` в его собственном окружении.
2. Для каждого персонажа создайте отдельный эксперимент в обучении: v2, 40k, F0 включён, извлечение высоты RMVPE. На GPU 4 ГБ начните с batch size 1 и отключённого кэширования датасета в GPU.
3. Выполните подготовку аудио, извлечение F0 и HuBERT-признаков, обучение и построение индекса. Понадобятся также pretrained_v2 и mute.zip из официальной инструкции.
4. Скопируйте экспортированную inference-модель из `assets/weights/` (не тренировочный G_*.pth/D_*.pth) и соответствующий added-индекс в папку персонажа выше. Обновите страницу: статус проверяется каждые 15 секунд.

Подробности стадий и CLI: [официальное руководство](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/docs/en/cli.md).

## Проверка

```powershell
venv\Scripts\python.exe -m pip install -r requirements-dev.txt
venv\Scripts\python.exe -m unittest discover -s tests -v
node --check script.js
```

Тесты проверяют декодирование, сохранение длительности и пауз, API, сообщения об отсутствующих моделях, параметры вызова RVC и очистку файлов. Для проверки звучания нужна обученная модель персонажа. `/api/status` сообщает об установленном движке и наличии файлов; веса персонажа фактически проверяются загрузчиком RVC при первой конверсии.
